# Azure Tags and Locks Guided Project

## Overview
This project focused on organizing and protecting Azure resources using Tags and Resource Locks.

## Azure Services Used
- Azure Resource Groups
- Resource Tags
- Resource Locks

## Project Tasks
- Created Azure resources
- Applied tags to resources
- Used tags for organization and management
- Created resource locks
- Tested Delete lock functionality
- Verified resource protection behavior

## What I Learned
- How tags improve organization and cost management
- Difference between Delete and Read-only locks
- How locks prevent accidental changes or deletions
- Importance of resource governance in Azure
